## 4. Scientific teaching contracts

A. `observation_state(measured=True,count=0)` → `MEASURED_ZERO`; `observation_state(measured=False,count=None)` → `UNMEASURED`. Invalid types and conflicting assay/count combinations fail closed.

B. `replication_summary(["donor_01"]*500 + ["donor_02"]*500)` → `{"technical_rows":1000,"biological_n":2}`. These are code-level counts, **not** donor independence proven by biology.

C. `evidence_verdict({"study_a":"PASS","study_b":"NOT_ESTIMABLE"})` → `NOT_ESTIMABLE`. Known required-source FAIL takes precedence; absent source blocks PASS. This is a toy status policy, not statistical evidence synthesis or a differential-expression test.

Baseline behavior: RED (faulty module) **4 passed/6 failed**, GREEN (correct module) **10 passed/0 failed**; full suite **22 passing tests** before audit's additional tests. An intentionally failing RED run is **not** a failed full CI workflow.
