- Confirm all placeholder names `gene_1` to `gene_3` and `cell_01` to `cell_12`, and the 6-donor CSV / separate 2-donor demonstration distinction.
- Read every Python example for runnable imports and explanatory language; ensure code fences and Markdown tables survive Medium import.

- Check external links and alt text. The article source uses raw GitHub URLs; Medium may need actual uploaded images.
- Cite software via `CITATION.cff` and **the exact code commit** readers used. Example citation: dushyant-mishra. (2026). *Scientific Regression Demo: RNA Data, Regression Tests, and GitHub Actions* [Software and teaching materials]. GitHub. https://github.com/dushyant-mishra/scientific-regression-demo (commit SHA).
- Don't invent a DOI. If Medium is published later, record publication URL/date separately from repository citation.
- Keep a finished copy/URL and publication confirmation in a new reviewed PR or a documented external receipt.
